# **Warehouse Object Triage** 

--- 

## **Description** 

This project is a simple Python application that simulates a warehouse object classification system. It reads a list of detected objects and classifies each object into the appropriate bin based on its temperature, color, and shape. 

The project also includes: 

- Object classification 

- Object filtering 

- Inventory management 

- Average weight calculation 

- Object counting by bin 

- Error handling for missing data 

- Unit testing 

--- 

## **Features** 

- Classify objects into different bins. 

- Filter objects by weight or color. 

- Store classified objects in an inventory. 

- Count objects in each bin. 

- Calculate average weight. 

- Handle invalid or missing object data safely. 

- Verify functionality using Unit Tests. 

## **Technologies Used** 

- Python 3 

- Python Standard Library 

- unittest
